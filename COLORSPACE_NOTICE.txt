Auto Node Runner - Colorspace Settings & GPL-3.0 Compliance Notice
==================================================================

Date: 2026-06-09

1. COLORSPACE MODIFICATIONS
----------------------------
The following colorspace changes support PBR-compliant texture workflows.

Template JSON files (ao.json, noao.json) - colorspace_name values:
  - BaseColor Image Texture: sRGB (color data)
  - AO Image Texture: sRGB (color data)
  - Metallic Image Texture: Non-Color (data map, PBR standard)
  - Roughness Image Texture: Non-Color (data map, PBR standard)
  - Normal Image Texture: Non-Color (data map, PBR standard)

ao.json additional change:
  - Mix node blend_type: "MULTIPLY" -> "BURN"
    (BURN blend mode produces more natural AO overlay)

These follow PBR texture conventions as documented in:
  - KhronosGroup/glTF 2.0 Specification
    https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html
  - Blender Manual: Color Space Settings
    https://docs.blender.org/manual/en/latest/render/shader_nodes/textures/image.html

2. GPL-3.0 COMPLIANCE - FILE CHANGE SUMMARY
---------------------------------------------
This project is a modified version of Node Runner (node_runner-1.4.1)
by Noah Thiering, originally licensed under GPL-3.0.

MODIFIED FILES (from node_runner-1.4.1):
  - __init__.py: Added i18n/panel module registration, fault-tolerant
    unregister with history.cleanup_nodetmp(), logging import,
    plugin renamed to "Auto Node Runner"
  - operators.py: Added Auto Texture operators (NODE_OT_match_textures,
    NODE_OT_apply_textures, NODE_OT_clear_texture_matches,
    NODE_OT_select_texture_directory), property groups
    (TextureMatchItem, NodeRunnerProperties), preferences with language
    selection (AUTO/en_US/zh_CN), i18n/history integration,
    template-based node application via deserialize_node_tree
    (_rewrite_template_paths, _rename_template_nodes,
    _remove_missing_links, _apply_template_to_material),
    fuzzy material name matching (_build_mat_name_pattern),
    external match_rules.json loading. Removed panel class to panel.py.
  - serialize.py: Added colorspace_name field serialization in
    serialize_image() (stores image.colorspace_settings.name for
    PBR color space preservation). Added dump_node() and
    dump_node_tree() debug/utility functions.
  - deserialize.py: Rewrote deserialize_image() logic - now assigns
    image to node first, then restores colorspace_settings.name from
    stored colorspace_name field. Original version only did
    load+assign without colorspace restoration.
  - conftest.py: Added ColorManagedInputColorspaceSettings stub class
    (name attribute) for colorspace_name serialization/deserialization
    test support. Added EnumProperty to bpy.props mocks.
  - ao.json: Set PBR-correct colorspace_name values (Non-Color for
    Metallic/Roughness/Normal, sRGB for BaseColor/AO). Changed
    blend_type from MULTIPLY to BURN.
  - noao.json: Set PBR-correct colorspace_name values (Non-Color for
    Metallic/Roughness/Normal, sRGB for BaseColor).
  - blender_manifest.toml: Changed id to auto_node_runner, name to
    "Auto Node Runner", version to 0.0.1 for addon isolation.

NEW FILES (not in node_runner-1.4.1):
  - i18n.py: Internationalization module (GPL-3.0)
  - history.py: History persistence module for nodetmp.txt (GPL-3.0)
  - panel.py: Auto Texture panel UI module (GPL-3.0)
  - match_rules.json: Regex match rules configuration (GPL-3.0)
  - COLORSPACE_NOTICE.txt: This notice file (GPL-3.0)

UNCHANGED FILES (identical to node_runner-1.4.1):
