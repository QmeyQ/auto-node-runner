Date: 2026-06-09

1. COLORSPACE MODIFICATIONS
----------------------------
The following colorspace_name changes were made in the template JSON
files (ao.json, noao.json) compared to node_runner-1.4.1 originals:

ao.json changes:
  - Metallic Image Texture: colorspace_name "sRGB" -> "Non-Color"
    (PBR standard: metallic maps are data, not color)
  - Roughness Image Texture: colorspace_name "sRGB" -> "Non-Color"
    (PBR standard: roughness maps are data, not color)
  - Normal Image Texture: colorspace_name "sRGB" -> "Non-Color"
    (PBR standard: normal maps are data, not color)
  - AO Image Texture: colorspace_name "sRGB" -> "sRGB" (unchanged)
  - BaseColor Image Texture: colorspace_name "sRGB" -> "sRGB" (unchanged)
  - Mix node blend_type: "MULTIPLY" -> "BURN"
    (BURN blend mode produces more natural AO overlay)

noao.json changes:
  - Metallic Image Texture: colorspace_name "sRGB" -> "Non-Color"
  - Roughness Image Texture: colorspace_name "sRGB" -> "Non-Color"
  - Normal Image Texture: colorspace_name "sRGB" -> "Non-Color"
  - BaseColor Image Texture: colorspace_name "sRGB" -> "sRGB" (unchanged)

These follow PBR texture conventions as documented in:
  - KhronosGroup/glTF 2.0 Specification
    https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html
  - Blender Manual: Color Space Settings
    https://docs.blender.org/manual/en/latest/render/shader_nodes/textures/image.html
